## 🚀 Featured Projects

### [PLC Sandwich](https://github.com/zewuro/plc-sandwich)

A low-cost PLC training device designed as an alternative to commercial training kits costing $100–$360.

**Hardware:**
- STM32F103
- 8 digital inputs
- 8 digital outputs
- OLED display
- Custom PCB

The device displays the logic gate being solved and was tested against all **96 input combinations**.

🎓 Bachelor's diploma project.

---

### [STM32_EDU](https://github.com/zewuro/stm32-edu-board)

A custom **4-layer STM32F103 development board** designed from scratch.

**Features:**
- STM32F103
- USB-C
- AMS1117-3.3
- SHT30 temperature & humidity sensor
- I²C
- SWD 2×5
- All GPIOs broken out
- 4-layer PCB

Designed in **KiCad**.
